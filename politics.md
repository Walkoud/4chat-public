4chat Privacy Policy

Données collectées : pseudonyme 4chat, mot de passe (voir note), description de profil, avatar, niveau/XP, et l'ID Discord lié au compte.
Usage : fonctionnement du tchat cross-server, affichage du profil, modération (ban).
Stockage : base de données MySQL hébergée par le développeur. Les messages ne sont pas conservés au-delà de leur relais instantané.
Partage : les pseudos et messages sont relayés publiquement dans les salons 4chat des serveurs utilisant le bot (par conception).
Droits : contacte le support pour suppression de compte.
Note sécurité : les mots de passe sont actuellement stockés en clair ; le développeur doit implémenter un hash (bcrypt) — en cours
